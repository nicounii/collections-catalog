# Perguntas frequentes (FAQ)

## O que é o Acervo do Marvete?

É o acervo pessoal de um único colecionador, disponibilizado para venda: quadrinhos,
mangás, action figures, retro gaming e livros de coleção. Cada peça é única.

## Os produtos são originais?

Sim. Todo item passa por inspeção de autenticidade e procedência antes de ser anunciado.
Quando houver qualquer ressalva, ela é informada na descrição.

## Como sei a condição de uma peça?

Cada anúncio traz o grau de condição (**Novo / Seminovo / Usado**) e observações
específicas. Veja o [Guia de condição](./condition-guide.md) para os critérios completos.

## Como faço para comprar?

- **Comprar:** itens com link de pagamento abrem a página do **Mercado Pago** em uma nova
  aba. Você paga com cartão, Pix ou boleto, conforme as opções do Mercado Pago.
- **Adicionar:** itens sem link de pagamento vão para o carrinho.
- **Negociar:** fale direto pelo **WhatsApp** para tirar dúvidas, pedir fotos ou combinar
  a compra.

## Vocês entregam para todo o Brasil?

Sim. Enviamos para todo o Brasil com rastreio e embalagem reforçada. Também há
**retirada em mãos em São Paulo, SP**. Veja [Envio e devoluções](./shipping-returns.md).

## Posso devolver um item usado?

Itens usados são vendidos **como descritos** (com defeitos e desgaste informados e
fotografados). A devolução é aceita se o item recebido for materialmente diferente do
anunciado. Detalhes em [Envio e devoluções](./shipping-returns.md).

## Como pago?

O pagamento é processado pelo **Mercado Pago** (cartão, Pix ou boleto). O site não
armazena dados de cartão.

## Posso parcelar?

As condições de parcelamento são as oferecidas pelo Mercado Pago no momento do
pagamento.

## Como falo com vocês?

Use o botão **Negociar** (WhatsApp) em qualquer anúncio ou os contatos no rodapé do site.

## Com que frequência entram novidades?

O acervo é de um único dono e é finito — as peças são adicionadas conforme a coleção é
organizada, e cada item é único. Peças vendidas saem do catálogo.
